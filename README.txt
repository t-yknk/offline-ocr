オフライン OCR ツール(画像 → テキスト / CSV)
==============================================

■ 使い方
1. このフォルダごと任意の場所にコピーします(USB メモリ等で別環境へ移行可)。
2. index.html をダブルクリックしてブラウザで開きます。
   「準備完了」と表示されたら使えます(数秒かかります)。
3. 画像をドラッグ&ドロップ(複数可)すると順番に文字を読み取ります。
   クリックして選択、Ctrl+V で貼り付けもできます。
4. 画像ごとに「保存」、または「すべて .txt で保存」(画像ごとに 1 ファイル)、
   「1 つのファイルにまとめて保存」。
   ※ 初回にブラウザが「複数ファイルのダウンロードを許可しますか」と尋ねたら許可してください。
   ※ 保存先はブラウザのダウンロードフォルダです。

■ 設定(抽出と出力形式は読み取り後でも切り替え可。再読み取りは不要)
- 文字の種類: 読む文字の範囲と並べ方を決めます。
  ・日本語(縦横は自動): 日本語の文字と英数字。縦書きか横書きかは、検出した
    文字列の向きから画像ごとに自動で判定します(結果は画像の下に表示)。
  ・日本語(横書きに固定)/(縦書きに固定): 自動判定が外れたときに使います。
    縦書きと横書きが混じる画像や、1〜2 文字の短い語ばかりの画像は外れることがあります。
  ・英数字のみ: 英数字と記号だけの画像向け。
  変更は、その後に読み取る画像から適用されます(読み取り済みは「再読み取り」)。
- 抽出「数字のみ」: 読み取った文字から数値だけを取り出します。
  「桁区切りのカンマを除く」で 12,800 → 12800。小数点と先頭のマイナスは残ります。
  「INV-2026」のように英数字の直後にあるハイフンは符号として扱いません。
- 出力形式「カンマ区切り (.csv)」: 1 行を 1 レコード、検出した文字のかたまりを
  1 列として出力します。BOM 付き UTF-8 なので Excel でそのまま開けます。
  「1 つのファイルにまとめて保存」では 1 列目に元画像のファイル名が入ります。
- 文字がごく小さい画像は、自動で拡大してから読み取ります(画像の下に表示されます)。
- 設定は次回開いたときも引き継がれます(ブラウザの設定によっては引き継がれません)。
- 画像の縮小表示をクリックすると、別のタブで大きく表示できます。
- 抽出や出力形式を切り替えると結果欄は作り直されます(手で編集した内容は上書きされます)。

■ 読み取りの特徴と限界
- 文字の位置を検出してから 1 か所ずつ読む方式です。傾いた画像は自動で補正します。
- 全角の英数字と記号は半角にそろえて出力します。
- 単語間の空白は出ないことがあります(例: 「SUS304 25A」→「SUS30425A」)。
- 「※」など一部の記号は読めません(出力されません)。
- ぼけた小さい文字では 1 文字抜けることがあります。手書きは苦手です。
- 大事な数値は、元の画像と見比べて確認してください。

■ 動作条件
- Chrome / Edge / Firefox の比較的新しい版。
- インストール不要・サーバー不要・インターネット接続不要。
- 画像は外部に送信されません。すべてこの PC のブラウザ内で処理します。
  さらに、ページからの外部通信をブラウザ側で禁止する設定(コンテンツセキュリティポリシー)を
  index.html に入れてあります。
- メモリを多めに使います(目安: 空き 1GB 以上)。

■ 対応形式
PNG / JPEG / BMP / GIF / WebP など、ブラウザが表示できる画像。
(PDF は非対応。画像に変換してから入力してください)
